Setup Guide
Step 1 — Go to supabase.com → New project (free tier is fine)
Step 2 — In SQL Editor, paste and run the supabase_setup.sql file. This creates all tables and the default admin.
Step 3 — Settings → API → copy Project URL and anon / public key
Step 4 — Paste both into MEQuote Settings → Database → Connect
Step 5 — Get a free Gemini key at aistudio.google.com → Paste into Settings → AI
Step 6 — Host on GitHub Pages: upload index.html to a public repo → Settings → Pages → main branch
